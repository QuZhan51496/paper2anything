# Poster Layout Design Guide

## Principles

Academic posters must balance **information density** with **visual clarity**. Key principles:

1. **Reading flow**: Left-to-right, top-to-bottom (Z-pattern)
2. **Visual hierarchy**: Title > Section headers > Key figures > Body text
3. **White space**: 15-20% of total area should be empty for readability
4. **Figure prominence**: Key contribution figure should be the largest visual element

## Standard Layout: 3-Column (48×36 inches)

```
┌──────────────────────────────────────────────────┐
│                  TITLE BAR                        │
│            Authors · Affiliations · Contact       │
├───────────────┬──────────────────┬────────────────┤
│               │                  │                │
│  Introduction │    Method /      │   Results      │
│  / Background │    Approach      │                │
│               │                  │   [Result      │
│               │  [Key Figure]    │    Table/Fig]  │
│               │                  │                │
│               │                  ├────────────────┤
│               │                  │                │
│               │                  │  Conclusion    │
│               │                  │  / Takeaways   │
│               │                  │                │
└───────────────┴──────────────────┴────────────────┘
```

## Column Assignment Strategy

| Column | Purpose | Content Type |
|--------|---------|-------------|
| Left   | Context setting | Introduction, Background, Related Work |
| Middle | Core contribution | Method, Architecture, Algorithm (with key figure) |
| Right  | Evidence + Summary | Results, Ablation, Conclusion |

## Sizing Guidelines

| Element | Font Size | Space Allocation |
|---------|-----------|-----------------|
| Title | 44-60 pt | 10-12% of height |
| Authors | 24-28 pt | Part of title bar |
| Section headers | 28-32 pt | 8-10% of section height |
| Body text | 18-22 pt | Remaining section space |
| Figure captions | 14-16 pt | Below figure |

## Figure Placement Rules

- No fixed figure quota — use as many or as few figures as the content needs; a section can be text-only. Just avoid clutter (don't pad with weak figures).
- Key figure (method/architecture) should get the most space
- Result figures/tables go in the right column
- Figure-to-text ratio within a section: ~40:60 or 50:50

## Common Mistakes to Avoid

- Too much text (poster is not a paper — use bullet points)
- Figures too small to read from 1 meter distance
- No visual hierarchy (everything same size/weight)
- Missing conclusion or key takeaway
- Overcrowded layout with no breathing room
