The problem with inference-time skills

Loading skills at runtime is a leaky abstraction.

Agent skills — structured packages of procedural knowledge and executable resources — are a reliable way to augment LLM agents. But injecting them at inference time has three structural costs.

Retrieval noise

Skill retrieval surfaces irrelevant guidance, steering the agent with content it never actually needed.

Token overhead

Injected skill text imposes a substantial context-token cost on every single step of every task.

No true acquisition

The model merely follows the skill — it never acquires the knowledge into its own parameters.

Abstract

What SKILL0 does

Agent skills have become a reliable mechanism for augmenting LLM agents. Yet inference-time augmentation is fundamentally limited: retrieval noise introduces irrelevant guidance, injected skill content imposes substantial token overhead, and the model never truly acquires the knowledge it merely follows. We ask whether skills can instead be internalized into model parameters, enabling zero-shot autonomous behavior without any runtime skill retrieval.

We introduce SKILL0, an in-context reinforcement learning framework for skill internalization. It uses a training-time curriculum that begins with full skill context and progressively withdraws it. Skills are grouped offline by category and rendered with interaction history into a compact visual context, teaching the model tool invocation and multi-turn task completion. A Dynamic Curriculum then evaluates each skill file's on-policy helpfulness, retaining only those from which the current policy still benefits within a linearly decaying budget — until the agent operates fully zero-shot.
